# Global Olympic Sports Performance Analysis

Responsive dashboard prototype inspired by the supplied project brief. Features:
- Medal totals by country and medal type
- Interactive region/sport filters and country search
- Trend and sports comparison charts
- Country comparison table and sample CSV export
- Three narrative scenarios and methodology notes

## Run
Open `index.html` in a browser. Internet is needed for Chart.js and Google Fonts CDNs.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.

## Data limitation
All displayed values are illustrative sample data, not official Olympic results. Replace with a verified source dataset and cite it before submitting as factual research. This front-end prototype does not itself create a Tableau workbook or Flask backend; those are possible extensions if required by your course rubric.
